# Katarzyna Bilicka

Personal academic website for Katarzyna Bilicka, built as a lightweight static
site for GitHub Pages.

## Preview locally

From this folder, run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Updating content

- Main page content: `index.html`
- Colors and layout: `styles.css`
- Search, filters, and mobile menu: `script.js`
- CV and papers: `assets/documents/`
- Portrait: `assets/images/`

GitHub Pages can publish directly from the `main` branch and repository root.
The included Pages workflow assembles the deployable site and preserves the
public CV, portrait, and working-paper files during deployment.
